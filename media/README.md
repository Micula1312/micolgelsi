# Media convention

Create one folder per project slug, for example:

- `public/media/archive-of-the-untamed/`
- `public/media/the-archive-is-alive/`
- `public/media/silent-target/`
- `public/media/abundance/`

Suggested files inside each folder:

- `avatar.gif` or `avatar.webp` / `avatar.webm` for the animated project avatar
- `01.jpg`, `02.jpg`, ... for still images
- `01.webm`, `02.webm`, ... for video loops
- `audio-01.mp3` for audio
- PDFs or other project documents when needed

Use paths such as `/media/archive-of-the-untamed/avatar.gif` in content frontmatter.
